مزامنة كافيه طلة الشمالي بين جهازين

1) أنشئ مشروعًا مجانيًا في Supabase.
2) افتح SQL Editor ونفّذ:

create table if not exists public.cafe_sync (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.cafe_sync enable row level security;
create policy "anon read cafe sync" on public.cafe_sync for select to anon using (true);
create policy "anon insert cafe sync" on public.cafe_sync for insert to anon with check (true);
create policy "anon update cafe sync" on public.cafe_sync for update to anon using (true) with check (true);

3) من Project Settings > API انسخ Project URL و anon public key.
4) افتح الموقع على الجهاز الأول > الإعدادات > المزامنة، ضع URL والمفتاح ورمزًا مشتركًا مثل talat-main ثم احفظ.
5) افتح الموقع على الجهاز الثاني وأدخل نفس URL والمفتاح ونفس رمز المزامنة، ثم اضغط مزامنة الآن.

ملاحظة: سياسة anon هنا مخصصة للاستخدام البسيط عبر رمز مزامنة مشترك. لا تضع بيانات حساسة أخرى في قاعدة البيانات. يمكن لاحقًا إضافة تسجيل دخول حقيقي لكل مستخدم مع RLS أكثر أمانًا.
