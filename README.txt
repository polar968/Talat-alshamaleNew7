كافيه طلة الشمالي — نسخة الجرد اليومي

هذه النسخة مخصصة للجرد اليومي المبسط:
- المبيعات اليومية
- المصاريف اليومية
- المشتريات اليومية كمبلغ إجمالي فقط
- الرواتب اليومية
- إجمالي الرواتب أسبوعيًا وشهريًا وسنويًا
- الفواتير الشهرية: تنكات مياه، كهرباء، إيجار محل
- التقارير والأرشيف
- تصدير Excel مرتب
- نسخة احتياطية واستعادة
- تنقل سهل بين التواريخ
- تأكيد آمن قبل الحذف

تم حذف: حضور وغياب، السلف، المخزون، الهالك، استهلاك المواد، رصيد الصندوق، مقارنة الأمس واليوم، والفواتير التفصيلية.


نسخة v19 المصححة:
- إصلاح إضافة وتعديل وحذف الموظفين.
- إصلاح حذف سجلات الرواتب والبحث فيها.
- إضافة النسخ الاحتياطي والاستعادة وتصدير Excel.
- إصلاح زر تثبيت التطبيق وتسجيل Service Worker.
- إصلاح مسح البيانات مع تأكيد.
- إصلاح لوحة الرئيسية والدوال المفقودة وحساب أسبوع الرواتب.
- تصحيح الربح بدون المبيعات ليكون التكاليف الخارجة فقط بالسالب.
- تحديث Service Worker لتفادي بقاء النسخة القديمة في ذاكرة التطبيق.
